# Modelagem-de-Dados
Ao longo do semestre na matéria de modelagem de dados foi trabalhado os conceitos como modelos conceituais, lógicos e agora o modelo físico. Acima estão alguns projetos de modelagem  físicas e conceituais feitas ao longo do semestre alguns mais fáceis e outros mais complexos.

# Atividade
Para fixar toda a teoria foi feito uma atividade avaliativa onde foi cobrado o conhecimento de modelos conceituais.Depois alguns desses modelos foram colocados no Mysql.
A atividade foi composta de vários cenários para trabalhar atributos,cardinalidade , relacionamento e entidades.

 # Ferramentas
Foi utilizado para criar os modelos conceituais a ferramenta br modelo é e claro também foi feito no caderno para os alunos aprenderem todos os conceitos necessárias .Esse modelo desenhado foi a base do modelo lógico e físico.
