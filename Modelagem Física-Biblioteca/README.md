 # Biblioteca 
 Foram criadas duas tabelas autor e livro sobre
 o cenário biblioteca onde foram colocados   atributos únicos 
 para cada tabela atributos como nome, gênero e etc.Para as chaves 
 primárias foram usados códigos únicos que podem identificar cada 
 autor e livro. As chaves estrangeiras trabalharam como foi ensinado na sala  onde a parte do muitos o N  tabela  livro recebe a chave estrangeira referente a tabela autor.
