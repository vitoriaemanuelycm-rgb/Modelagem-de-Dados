# Berçário 
Esse cenário foi composto por 3 tabelas médico, mãe, bebê foram colocados várias atributos como formação,nome, telefone e etc além das chaves primárias que foram CRM(médico)
CPF(mãe) Pulseira _identificadora (bebê) também teve as chaves estrangeiras que foram colocadas no relacionamento correspondente ao muitos do relacionamento no caso o N que foi a tabela bebê.
# Comandos 
Foram usados comandos DDL que são create database e create table além de declaração de 
dados e o tipo de dados para cada informação a ser registrada.
