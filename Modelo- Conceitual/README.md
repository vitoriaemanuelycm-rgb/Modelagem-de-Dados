## Atividade
Atividade passada no começo do semestre com 11 questões 
para trabalhar os modelos conceituais onde foram
colocados vários cenário para os alunos trabalharem 
relacionamento,entidade, cardinalidade, atributos e chaves primárias.
Essa atividade foi desenha no caderno e no Br modelo para Patrícia e reforça os conceitos antes de passar para o modelo lógico e físico.
